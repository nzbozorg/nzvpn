## ب) ساخت نسخهٔ انتشار

کلید امضا نزد مالک برنامه است: `keystore/nz-release.jks` (alias: `nzvpn`).
**فایل کلید و رمزها عمداً داخل ZIP سورس منتشر نمی‌شوند**؛ رمز را جداگانه از مالک بگیرید.

```bash
export nzKeystore=keystore/nz-release.jks
export nzKeystorePassword='<رمز-شخصی>'
export nzKeyAlias=nzvpn nzKeyPassword="$nzKeystorePassword"

bash tools/publish.sh                # ساخت release + ارسال به تلگرام
./gradlew :app:assembleRelease -PnzKeystore=… -PnzKeystorePassword=… -PnzKeyAlias=… -PnzKeyPassword=…
./gradlew :app:bundleRelease   -PnzKeystore=… … -PnzMinify=true   # AAB برای پلی (R8 روشن)
```

> اگر رمز کلید را عوض کردید، هم `keystore/keystore.properties` و هم دستور بالا را به‌روز کنید.

- [ ] فایل `nz-release.jks` و رمزها را **جای امن** نگه دارید (گم شود، دیگر نمی‌توانید به‌روزرسانی بدهید)
