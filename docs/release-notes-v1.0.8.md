## English

### What's new in NZVPN 1.0.8

- **More reliable smart connect:** Servers from all folders enter the same race. The first server with a *fresh* successful response is selected, rather than one with a previously cached ping. Native probes are limited to six concurrent calls.
- **Faster folder tests:** Each server has up to one second to produce a result for the UI. Successful results appear and are sorted by latency as they arrive; late native results are ignored.
- **New settings panel:** App information, completely optional support, update checks, and sharing are in one place. The home-screen share button remains available.
- **Verified updates for future releases:** The app checks stable releases from this repository and validates an update APK's package, version, both architectures, and signing identity against the installed app before opening Android's installer. Installation always requires your confirmation.

Separate subscription folders, independent refresh, clipboard and file import, flags, and the Persian right-to-left interface remain available.

### Download and install

Download **`NZVPN-1.0.8-universal-release.apk`** from this release's **Assets** and install it on **Android 8.0 or newer**. The single APK supports both `arm64-v8a` and `armeabi-v7a`. You will need your own server configuration or subscription to connect; no VPN servers or accounts are bundled with the app.

**APK SHA-256:**

```text
e2064ac7d52a22ec40b74e33ffd0fe5436e70205b0c1d40554fe20a909078b67
```

**Validation:** All 24 JVM tests passed, and the APK signature and architectures were checked. Connection and update installation for 1.0.8 have not yet been tested on a physical device.
