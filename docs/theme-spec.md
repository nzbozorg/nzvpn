1. هویت و حس کلی تم
==================================================

این طراحی یک رابط تاریک، سینمایی، صنعتی و حرفه‌ای است که از ترکیب رنگ‌های مشکی، مسی، کرم، آبی فیروزه‌ای و قرمز محدود استفاده می‌کند.

ویژگی‌های اصلی:

- Dark Cinematic UI
- Industrial Editorial Design
- Copper and Gunmetal Aesthetic
- Premium Minimal Interface
- High Contrast
- Spacious Layout
- Subtle Grid and Film Grain
- Restrained Glow
- Thin Industrial Borders
- آرام، جدی و حرفه‌ای
- بدون ظاهر شلوغ و گیمینگ
- بدون Glassmorphism شدید
- بدون گرادینت‌های بنفش و صورتی کلیشه‌ای

هدف این است که رابط مانند یک کنسول کنترل پیشرفته، دقیق و قابل اعتماد به نظر برسد؛ اما خوانایی و سادگی آن حفظ شود.

9. Motion و انیمیشن
==================================================

زمان‌های پیشنهادی:

Micro Interaction: 180ms تا 260ms
Standard Transition: 220ms تا 350ms
Large State Change: 500ms تا 900ms
Ambient Pulse: 3 تا 5 ثانیه
Background Movement: 18 تا 28 ثانیه

Easing پیشنهادی:

Fast Out, Slow In
Cubic Bezier: (0.4, 0.0, 0.2, 1.0)

انیمیشن‌های مجاز:

- Fade نرم
- جابه‌جایی کوتاه 4dp تا 12dp
- تغییر تدریجی Border
- تغییر نرم رنگ وضعیت
- Pulse بسیار محدود برای وضعیت مهم
- افزایش تدریجی اعداد
- حرکت آرام بافت پس‌زمینه

انیمیشن‌های ممنوع:

- Bounce زیاد
- چرخش دائمی تزئینی
- حرکت سریع عناصر
- Glow شدید روی تمام صفحه
- انیمیشن هم‌زمان تعداد زیادی از اجزا
- تغییر ناگهانی اندازه
- انیمیشن‌هایی که مانع تعامل کاربر می‌شوند

حتماً تنظیم Reduced Motion یا Animator Duration Scale سیستم رعایت شود.

13. پرامپت آماده برای AI
==================================================

Design and implement a premium dark interface using a cinematic industrial editorial design system.

The visual direction must use near-black surfaces, warm copper accents, off-white typography, restrained cyan status highlights, and limited red warning states. The interface should feel precise, premium, secure, spacious, and professional.

Do not use character illustrations, human portraits, robots, cyborgs, or decorative mascots. Focus only on the interface design system, layout, typography, components, states, and subtle background effects.

COLOR SYSTEM:
- Background: #090A0C
- Primary surface: #111317
- Elevated surface: #171A1F
- Secondary surface: #20242A
- Primary text: #E9E4D9
- Secondary text: #B7B4AD
- Muted text: #9D9A92
- Primary copper: #C27D4D
- Bright copper: #D88752
- Copper highlight: #E09A62
- Cyber cyan: #5DD6F4
- Deep cyan: #286678
- Warning red: #FF3227
- Error red: #DC2626
- Border: rgba(233,228,217,0.15)
- Strong border: rgba(233,228,217,0.28)

TYPOGRAPHY:
- Use Cormorant Garamond, Noto Serif, or Georgia for large editorial headings.
- Use Inter or Roboto for UI content.
- Use JetBrains Mono or Roboto Mono for technical values, status labels, codes, IP addresses, speed, and time.
- Keep headings large, short, high contrast, and tightly spaced.
- Use copper selectively for one important word or label.

LAYOUT:
- Use a mobile-first responsive layout.
- Use spacious sections and clear visual hierarchy.
- Use a 4dp spacing system.
- Page margins should be 16dp to 20dp on mobile.
- Cards should become multi-column only when enough width is available.
- Use adaptive layouts for phones and tablets.

CARDS:
- Background: #111317
- Border: 1dp rgba(233,228,217,0.15)
- Radius: 8dp to 12dp
- Padding: 16dp to 20dp
- Very low or zero elevation
- Use borders and surface contrast instead of large shadows.
- Active cards may use copper borders.
- Successful or live cards may use a thin cyan indicator.

BUTTONS:
- Minimum height: 48dp
- Primary button: off-white or copper background with near-black text.
- Secondary button: transparent background with a subtle border.
- Danger action: red accent only.
- Avoid excessive rounding and pill-shaped buttons unless appropriate.
- Pressed and focused states must be clearly visible.

ICONS:
- Use Material Symbols Rounded or Lucide-style line icons.
- Default icon color: #9D9A92
- Active icon color: #D88752
- Success icon color: #5DD6F4
- Error icon color: #FF3227
- Do not use emojis as icons.

BACKGROUND:
- Use a near-black base.
- Add an extremely subtle industrial grid at 3% to 5% opacity.
- Add fine film grain at 3% to 6% opacity.
- Use a soft cyan ambient light from one side and a soft copper ambient light from the other.
- Keep background effects subtle enough to preserve readability.
- Do not use character art or large decorative illustrations.

MOTION:
- Micro interactions: 180ms to 260ms.
- Standard transitions: 220ms to 350ms.
- Large state transitions: 500ms to 900ms.
- Ambient effects: 18 to 28 seconds.
- Use subtle fades, short translations, border changes, and restrained status pulses.
- Avoid bounce, fast rotation, excessive glow, and simultaneous animation of many elements.
- Respect reduced-motion preferences and system animator settings.

ACCESSIBILITY:
- Minimum touch target: 48dp.
- Minimum text contrast: 4.5:1.
- Support screen readers and meaningful content descriptions.
- Never communicate state using color alone.
- Support font scaling.
- Prevent essential text from clipping or truncating.
- Provide visible focus states.

AVOID:
- Purple and pink AI gradients
- Excessive glassmorphism
- Heavy shadows
- Excessive neon
- Over-rounded components
- Gaming-style clutter
- Low-contrast text
- Decorative animation without purpose
- Character illustrations or mascots

The final result should feel like a refined industrial control interface: dark, copper, precise, cinematic, modern, accessible, and highly usable.
