# NZVPN ۱.۱.۰ — کنترل بیشتر روی ساب و اتصال

- برای ساب‌هایی که **خودت اضافه کرده‌ای** و سرویس‌شان آمار حجم معتبر می‌فرستد، دکمهٔ «حجم ساب» اضافه شد: مصرف‌شده، باقی‌مانده، حجم کل و نوار مصرف را می‌بینی. ساب‌های پیش‌فرض و ساب‌های بدون آمار دکمه ندارند.
- کنار سرور انتخاب‌شده یا در حال استفاده روی کارت اتصال ستاره گذاشته شد تا سریع در «ذخیره‌شده‌ها» نگهش داری.
- بعد از ارتقای برنامه، یادداشت تغییراتِ **همان نسخهٔ نصب‌شده** از Release متناظر گیت‌هاب نمایش داده می‌شود؛ اگر هنوز منتشر نشده باشد یا اینترنت نداشته باشی، در ورودهای بعدی دوباره تلاش می‌کند.
- آپلود و دانلود کارت اتصال از نشان وضعیت جدا شدند تا متن‌ها روی هم نیفتند.
- موقع «در حال اتصال»، دکمهٔ فعال «لغو اتصال» می‌بینی؛ تلاش اتصال و هسته واقعاً متوقف می‌شوند.
- در «اطلاعات برنامه»، راه‌های دسترسی به کانال NZBOZORG، وب‌سایت، مخزن برای ستاره‌دادن و پروفایل شخصی اضافه شدند.

APK مشترک نسخهٔ ۱.۱.۰ با همان گواهی نسخه‌های قبلی برای `arm64-v8a` و `armeabi-v7a` ساخته و بررسی شده است. نصب نهایی آپدیت با تأیید خودت انجام می‌شود. این برنامه **کلاینت** است و اشتراک یا سرور VPN ارائه نمی‌کند.

کد در فایل `NZVPN-1.1.0-source.zip` قرار دارد. ۳۶ آزمون JVM موفق بوده‌اند؛ تجربه و اتصال واقعی، لغو در شرایط شبکهٔ مختلف و ساب‌های واقعی باید روی گوشی آزموده شوند.

> این فایل فقط متن پیشنهادی برای Release **احتمالیِ آینده** است؛ تا زمانی که مالک تأیید نکرده، ۱.۱.۰ در GitHub منتشر نشده است.
